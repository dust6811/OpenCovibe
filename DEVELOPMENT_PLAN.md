# План развития форка OpenCovibe

Этот документ описывает стратегию развития твоей версии OpenCovibe с уникальными функциями.

---

## 🎯 Видение

Создать версию OpenCovibe с:
1. **Поддержкой 1M контекста** для Claude Opus 4.6 / Sonnet 4.6
2. **Гибким управлением разрешениями** (глобальное + пер-сессия + пер-агент)
3. **Split-view панелью** для удобной работы с файлами
4. **Дополнительными функциями** для power users

## 🔮 Планируемые функции (v0.3-v0.4)

### 4. Always Allow правила (UI)

**Описание:** UI для управления правилами "Always Allow" прямо из приложения

**Функционал:**
- Просмотр текущих правил (user + project)
- Добавление/удаление правил
- Glob-паттерны для файлов
- Включение/выключение правил

**Файлы для создания:**
- `src/routes/settings/permissions/+page.svelte` (новая страница)
- `src/lib/components/PermissionRulesEditor.svelte` (новый компонент)
- Tauri commands для чтения/записи `~/.claude/settings.local.json`

---

### 5. Профили разрешений

**Описание:** Сохранение наборов правил для разных типов задач

**Примеры профилей:**
- 🔒 **Secure** — спрашивать всё
- ⚡ **Standard** — авто-редактирование, спрашивать команды
- 🚀 **Full Auto** — никаких вопросов (для доверенных проектов)

**Файлы для создания:**
- `src/lib/stores/permission-profiles.svelte.ts`
- `src/lib/components/PermissionProfileSelector.svelte`

---

### 6. История сессий с фильтрами

**Описание:** Улучшенный просмотр истории с фильтрами по режиму разрешений

**Функционал:**
- Фильтр по permission mode
- Фильтр по агенту
- Фильтр по использованным инструментам
- Экспорт статистики

**Файлы для модификации:**
- `src/routes/history/+page.svelte`
- `src/lib/stores/session-store.svelte.ts`

---

### 7. Быстрые команды для Permission Mode

**Описание:** Хоткеи для переключения режима прямо во время чата

**Примеры:**
- `Ctrl+Shift+A` — циклическое переключение режимов
- `Ctrl+Shift+F` — быстро включить Full Auto
- `Ctrl+Shift+S` — быстро включить Ask

**Файлы для модификации:**
- `src/lib/stores/keybindings.svelte.ts`
- `src/routes/chat/+page.svelte`

## 📞 Связь с upstream

### Как предлагать изменения:

1. **Создай issue** с описанием проблемы
2. **Предложи решение** перед тем, как писать код
3. **Создай PR** с чётким описанием изменений
4. **Будь готов к code review** и итерациям

### Чего избегать:

- ❌ Большие PR (>500 строк) — разбивай на части
- ❌ Изменения стиля кода без функциональных улучшений
- ❌ Ломание существующего API
- ❌ Игнорирование code review комментариев
